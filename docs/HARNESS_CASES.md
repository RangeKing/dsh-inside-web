# 六个执行案例：内容与验收

2026-09-24，用户在 grilling 中确认方案并授权执行。替代八个生活案例、分账四条预设路线与首页请假主线。保留六例、大肥鲸、双语、深浅主题、静态教学、独立链接、源码阅读和本地日志查看器。

## 选题标准

每例必须说明：实际改变了什么、根据反馈怎样调整、凭什么确认完成。DSH 机制解释执行过程，不声称这些机制为 DSH 独有；带工具的聊天产品也可能包含 Harness。简短文件是可核对的教学样本，不代表真实任务规模或性能测量。

| ID / 题目 | 推荐路径的交付 | 关键分岔与另一结果 | 能力前提 |
|---|---|---|---|
| `repair-site` 救活一个打不开的网站 | 修正 server.mjs；本地启动、首页 200 与标题检查 | 跳过复测 → 待验证，不宣布成功 | Standard、文件工具、Shell、Node.js；文件观察策略 |
| `archive-files` 整理文件，别把原件弄丢了 | 3 个文件按清单移动，大小和 SHA-256 对上，保留同内容独立文件 | 拒绝移动 → 文件保持原位，归档未完成 | Standard、Shell；逐次移动审批；不覆盖与不删除是本例任务规则 |
| `shared-project` 接手一个正在被别人修改的项目 | timeoutMs=8000，保留同事的 retries=4 | 不重读继续 edit → FS_STALE_VERSION，任务未完成 | 文件工具 + fs-observation-policy；不推广到 Shell 写入 |
| `data-pipeline` 把一堆脏表格变成交付数据 | 5 条有效、1 条重复、3 条异常覆盖 9 条源记录；有效合计 220 元 | 取最后一条并将坏值当零 → 校验失败，阻止交付 | PTC、ptcRuntime、文件工具；当前生成的 SDK；业务清洗规则显式给定 |
| `incident-report` 查清一场故障，证据不能丢 | 带文件/行号的调查报告，保留其他因素未排除的限制 | 仅凭有损摘要 → 根因未确定，需原文 | Standard、进程内子任务提供方、自动压缩和裁剪；只读调查 |
| `pixel-company` 开一家像素 AI 公司 | 办公室运行时/Client 分别确认；番茄钟返工、复测与交付 | 忽略 restart-required → 未生效，订单未开始，样例不解锁 | Creator、Web Profile、Plugin Manager 授权；本例 HMR 关闭 |

## 数据与界面契约

- `data/scenarios.json` 是当前案例内容源，`data/locale-cases.json` 保存配套英文，构建入口仍为 `npm run build`。旧迁移脚本仅适用于历史版本，不能重新生成当前六例。
- `src/case-paths.js` 统一路径选择、索引限制与分岔暂停判定。每例有一个 `decision`、一个默认路径和两个 `variants`。
- 时间线、步骤说明、模型相关节点、成功样式和结果文件均读取当前路径。成功由明确的路径验收结果决定，不以到达最后一步判断。
- 自动播放遇到未确认分岔暂停；键盘或点击选定路径后再播放。直接 seek 用于自由阅读，不限制访问结尾。切换路径回到分岔处并停止播放。
- 结果文件按钮展示所选路径的教学交付物。共享项目被拒时展示未改变的状态，公司未生效时不提供已交付假象。
- 旧案例链接映射到新的相关案例；保留 `task`、`step`、`branch` 查询语义。旧 `make-tool` 映射到公司。
- 四预设独立比较组成和运行条件，取消分账路线、计算器和不再使用的航行档案阅读器；本地日志导入保持原有功能与隐私边界。

## 首页

“把这个打不开的网页修好”贯穿输入、错误回流、文件修改与验证交付。插件安装、长上下文和委派仍讲解，但明确是扩展能力；这次小修复不必安装新插件或强行委派。七步循环动画的后半段是多次工具往返的概览，不把多次调用冒充单次 Step。

## 证据与验证

DSH 行为依据 `docs/UPSTREAM_AUDIT.md` 的本轮核验。所有命令输出、审批答复、外部修改和子任务报告均为本页教学编排；没有实际调用模型或安装办公室插件。

本地检查独立执行修复样本：原脚本出现 ENOENT，修正后实际 HTTP 请求返回 200 与预期标题；这验证样本的一致性，不是 DSH 执行验证。表格结果独立复算，归档样本哈希独立计算。浏览器覆盖与限制见 `docs/QA.md` 的本轮记录。
