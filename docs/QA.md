## 2026-09-24 鲸鱼模型返工

用户反馈 `a3ca58e` 之后鲸鱼“全是毛刺，还不如修改之前”。在 Blender 工作台渲染（侧面、3/4、腹部、头部）和实际页面 2× 截图中对比修改前后，确认原因：

- `a3ca58e` 按面给主艇分配深色 / 象牙色两种材质。原始网格的三角面很碎，分区边界沿三角形走成锯齿，腹侧和眼斑边缘出现一排尖刺；深色区还夹着按面误判的白色碎块。
- 修改前原本就有的碎面感，来自两张贴图：一张颜色贴图（烘焙了明暗和杂点），一张法线贴图（叠加出细碎反光）。

处理：主艇几何保持原样，在贴图空间重建颜色贴图（深色 / 象牙色 / 青色三类，颜色取原贴图的中位色，先去杂点，再给边界抗锯齿）；去掉法线贴图和金属度-粗糙度贴图；只在夹角小于 22° 的相邻面之间平滑法线，面板边缘保持清晰。30° 会让头部出现明暗斑块，细分会拉开面板之间的缝，这两种都已试过并放弃。另外，模块倒角宽度改为受最薄一边限制，审批气闸栏杆端部的细碎尖角随之消失。

结果：主艇 62.6k 三角面，0.99 MB（原 11.1 MB）；首页 13 个模型合计 1.9 MB。`npm run check` 17/17，实际 GLB 过渡审计桌面与手机 7 个边界通过，滚动 p50 / p95 为 16.7 / 16.8 ms。已检查首页英雄区、终章、拖动开壳、手机端和案例页；深色与浅色主题下都没有毛刺。

## 2026-09-24 像素公司案例：减少动态与分步场景

- 问题 1（“减少动态”没反应）：按钮本身能切换 `state.reduced`，文字也会变；但像素公司面板在 3D 画布之上，完全不读这个状态，所以切换后画面没有任何变化。现在面板会接收 `reduced`：开启时不做场景淡入淡出，不闪报警红光，当前岗位不闪烁；关闭后恢复。系统级“减少动态”设置同样生效。
- 问题 2（像素画不随进程变化）：原先 9 步只用一张 `pixel-office.png`，只有第 5 步以后叠一排 HTML 小人。现在每个阶段一张场景图（`assets/office/*.webp`，共 1.7 MB）：接单 → 检查接口 → 打包插件 → 插电安装 → 分派 → 设计开发 → 测出 bug → 交付 → 下班拔插头。相邻两步之间有 0.7 秒淡入淡出，并预载下一张。
- 场景图通过 ChatGPT.app 自带的 Codex CLI 调用 OpenAI 图像生成（使用用户的 ChatGPT 登录），以原办公室图为参考保持构图一致；每张图的提示词、原始输出路径与哈希记录在 `assets/image-provenance.json`。连接用户 Chrome 的 DevTools 端口超时，没有走网页版 ChatGPT。
